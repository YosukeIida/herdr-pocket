| 1 | コードが、その host:port に pin 済みの host key を確認なしに置き換える | 修正 | pin と異なる host key のコードを `pair` が拒否し、両方の fingerprint を示す。マシンを入れ直した場合は、先に設定で古い host key を消す |
| 2 | 名前の引数に改行があると、制限の無い 2 行目が authorized_keys に入る | 修正 | 名前に使える文字を英数字・`.`・`_`・`-` に限った。公開鍵のファイルが 1 行であることも確かめる |
| 3 | シグナルで終わると EXIT の trap が動かず、秘密鍵が一時フォルダに残る | 修正 | HUP・INT・TERM でも後始末を実行する |
| 4 | 末尾に改行の無い authorized_keys では、追記した行が最後の行につながる | 修正 | 末尾が改行でなければ、先に改行を足す |

| 6 | 鍵を書いた後に host key の書き込みが失敗すると、古い鍵が失われる | 修正 | pin の確認と書き込みを鍵より先に行う。Keychain はその場で更新するので、鍵の書き込みが失敗しても古い鍵が残る |

- アプリでマシンを削除しても、マシン側の行は消えない。README に、登録を外すときはその行を消すと書いてある。
